# Trojan Detection - Quick Start

1. Clone repo
2. Install dependencies
3. Set the paths to the datasets inside `Trojan_detection.py`
4. Run main module: `python Trojan_detection.py`
5. Access [Module documentations](https://souren-0.github.io/Studienprojekt-Trojaner/) online
6. Or build them locally using:
   ```bash
   cd docs
   make html
   start build\html\index.html
   ```
